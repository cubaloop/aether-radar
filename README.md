## ?? Quick Start (Local)

```bash
git clone https://github.com/cubaloop/aether-radar.git
cd aether-radar
pip install -r requirements.txt
cp .env.example .env
# Add your GROQ_API_KEY into .env
python -m uvicorn aether_engine:app --host 0.0.0.0 --port 8095
```

Open your browser at `http://localhost:8095/`.
